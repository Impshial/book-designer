## Next milestones

1. Finish foundation hardening: native recents/default folder, recovery decisions, external-change detection, keyboard/IME and scaling tests, asset memory limits, native GUI automation coverage.
2. Complete Picture Book/Text-only controls: in-place text editing, full geometry operations, font/style model, headers, TOC, document import and incremental pagination.
3. Add real Hybrid anchors and deterministic rectangular wrapping, stable deletion behavior, and spread-spanning originals.
4. Build semantic DOCX and both EPUB output models, with package validators and preview readers.
5. Build cover/edition workflows; verify and version KDP/IngramSpark rules; evaluate a color-managed print engine and actual output profiles.
6. Expand Kindle-specific behavior, advanced covers, contour wrapping and interchange only after their validation paths exist.
