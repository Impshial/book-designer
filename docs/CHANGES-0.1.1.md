# Changes in 0.1.1

- New Book keeps the same dimensions across Picture Book, Hybrid and Text Only, in that order. Advanced settings scroll inside the dialog.
- New Book traps focus and temporarily disables the native main window's minimize, maximize, close and resizing controls.
- A save location is optional. Unsaved new books live in memory until Save opens the destination picker.
- Closing or replacing an unsaved/edited book offers Save, Discard and Cancel. Failed or cancelled saves leave the work open. Recovery snapshots for existing files no longer overwrite explicit saves.
- Text Only and Hybrid chapters are editable directly on paginated paper with one scroll area and a sticky formatting bar. Print preview is a separate optional view.
- Picture-book text frames reflow at their original font size during a resize. Undo restores the entire resize in one step.

Existing version-1 project files remain compatible. This update does not add the remaining export formats or publishing milestones listed in FEATURE-STATUS.md.
